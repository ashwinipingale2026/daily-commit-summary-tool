# Python Calculator

A simple Python calculator project with basic addition, subtraction, and multiplication functions.

## Files

- `calculator.py`: Defines `add()`, `subtract()`, and `multiply()` functions.
- `main.py`: Demonstrates how to use the calculator functions.

## Run

```bash
python main.py
```

Example output:

```text
10 + 4 = 14
10 - 4 = 6
10 * 4 = 40
```
