# Create Status Report

- Turn raw notes, commit logs, or task updates into a short, professional weekly status report.
- Read source material (commit log, notes, task updates) completely before writing.
- DO NOT exceed 20 lines total in the generated report.
- DO NOT use fluff words (e.g. "just", "really", "basically", "very", "actually", "in order to").
- DO NOT write in paragraphs — use bullet points only.
- DO NOT include sections other than Accomplishments, Blockers, Next Week.
- ONLY output Markdown.
- Output format:
  ```markdown
  # Weekly Status Report

  ## Accomplishments
  - {bullet point}

  ## Blockers
  - {bullet point, or "None"}

  ## Next Week
  - {bullet point}
  ```
- Keep tone professional and direct.
- Each bullet should be a single, specific, complete statement — no filler, no hedging.
